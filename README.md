# 🗺️ R Markdown & Leaflet Map — Legacy Course Exercise

A small learning exercise using **R Markdown** and the **leaflet** package to create an interactive web map with a custom marker and popup.

## 🎯 What It Demonstrates

- Creating an interactive Leaflet map in R
- Adding map tiles
- Creating a custom icon
- Adding geographic markers
- Embedding HTML content in popups
- Combining interactive visualization with R Markdown

## 📄 Source File

The exercise is implemented in [`code.rmd`](code.rmd).

## 🧭 Example

The map places a marker at **Benrath Palace** and demonstrates how an image/link can be embedded inside a Leaflet popup.
